# Claude Writer

A Claude Code plugin marketplace for fiction writing tools.

## Installation

In Claude Code, add this marketplace:

```
MeatMan122/claude-writer
```

Then install the Fiction Forge plugin from the plugin browser.

## Available Plugins

### Fiction Forge

A comprehensive fiction writing studio that guides you from initial spark to finished manuscript, following the structural principles of Robert McKee's *Story*.

See [Fiction Forge README](plugins/fiction-forge/README.md) for full details.
