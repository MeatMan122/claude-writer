# Phase Map: Detailed Transition Rules

## Phase: Ideation → Broad Outline
**Prerequisites**:
- Core concept established (genre, format, length)
- At least one protagonist sketched
- Central conflict identified
- Story seed documented in appendix
**Transition Action**: Update PROJECT.md, create initial appendix entries, set phase to broad-outline

## Phase: Broad Outline → Detailed Outline
**Prerequisites**:
- Story structure selected (Archplot/Miniplot/etc.)
- All major plot beats filled in
- User has explicitly approved the broad outline
**Transition Action**: Save broad-outline.md, update PROJECT.md

## Phase: Detailed Outline → Writing Plan
**Prerequisites**:
- Scene-by-scene breakdown complete
- Chapter divisions finalized
- User has explicitly approved the detailed outline
**Transition Action**: Generate chapter breakdown document, update PROJECT.md

## Phase: Writing Plan → Writing
**Prerequisites**:
- Chapter breakdown finalized
- Character appendix entries complete for major characters
- Writing schedule agreed upon
**Transition Action**: Create chapter draft files, update PROJECT.md, set first chapter as active

## Phase: Writing → Revision
**Prerequisites**:
- All chapters drafted
- Beta reader feedback collected (optional but recommended)
- User ready to begin revision pass
**Transition Action**: Archive drafts, create revision checklist, update PROJECT.md

## Phase: Revision → Complete
**Prerequisites**:
- All revision passes completed
- Final polish done
- User satisfied with manuscript
**Transition Action**: Archive final version, update PROJECT.md, congratulate author

## Backwards Transitions
- Any phase can go back to any previous phase
- When going back: preserve current work, don't delete
- If going back to ideation: create a new project variant directory (append -v2, -v3, etc.)
- Always ask user to confirm backward transition

## Stalled Project Detection
- If user has been in the same phase for 3+ interactions without progress, gently ask if they want to:
  - Take a different approach to this phase
  - Go back to a previous phase
  - Take a break and come back later

## Phase Duration Expectations
- **Ideation**: 1-3 sessions (30-90 minutes)
- **Broad Outline**: 2-4 sessions (1-2 hours)
- **Detailed Outline**: 2-5 sessions (1-3 hours)
- **Writing Plan**: 1-2 sessions (30-60 minutes)
- **Writing**: Varies by project length (could be many sessions)
- **Revision**: 2-5 sessions depending on scope (1-3 hours)

## Emergency Reset Protocol
- If user says "start over" or "I want to begin a new project":
  1. Ask if they want to preserve the current project
  2. Preserve by renaming current directory (append -archive)
  3. Create fresh project directory
  4. Begin new PROJECT.md
  5. Hand off to Story Ideation skill
